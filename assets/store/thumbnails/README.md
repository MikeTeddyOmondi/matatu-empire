# Store thumbnails

16:9 at 1920x1080 (.png or .jpg), up to 10 images and videos per experience. Uploaded in the
Creator Dashboard on the start place, under Thumbnails. Keep the bottom strip clear: player
counts cover it.

| File | What it is |
| --- | --- |
| `01-key-art.png` | Title card rendered from the game's matatu model (`just store-art`) |

Add in-game captures here as you take them (Studio, press P for framed shots; see the README),
numbered in the order they should appear, for example `02-railways-stage.png`,
`03-uhuru-highway.png`, `04-kibera.png`.
